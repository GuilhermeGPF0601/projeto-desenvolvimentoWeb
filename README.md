# Portfólio — Guilherme Peres

Site pessoal de portfólio desenvolvido para a disciplina de **Desenvolvimento Web**. O projeto apresenta informações sobre Guilherme Peres, seus interesses, hobbies e projetos futuros em uma interface responsiva, organizada e com identidade visual personalizada.

## Sobre o projeto

A página foi construída em HTML com Bootstrap 5 e contém:

- apresentação profissional e acadêmica;
- menu de navegação responsivo;
- carrossel com imagens e destaques;
- cards sobre projetos e interesses;
- acordes com os jogos favoritos;
- modais com informações e imagens dos jogos;
- seção de projetos futuros;
- identidade visual personalizada em CSS.

## Funcionalidades

- Navegação por âncoras entre as seções
- Layout responsivo para dispositivos móveis e desktops
- Carrossel de conteúdo na seção principal
- Acorde interativo de jogos
- Modais com detalhes de Counter-Strike 2, Elden Ring e GTA 6
- Tema visual escuro com destaque em azul e magenta

## Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Bootstrap Bundle

## Como executar

Não é necessário instalar dependências ou configurar um servidor.

1. Clone o repositório:

```bash
git clone https://github.com/GuilhermeGPF0601/projeto-desenvolvimentoWeb.git
```

2. Acesse a pasta do projeto:

```bash
cd projeto-desenvolvimentoWeb
```

3. Abra o arquivo `index.html` diretamente no navegador ou utilize uma extensão como **Live Server** no VS Code.
